宵空天文台 — Ver.7
====================

【公開】
index.html、map_clean.png、staff_art.png、title_art.png、sera_sprite.png、player_sprite.png、sera_portrait.png、sera_sleep.png、eye_lit.png、eye_empty.png を同じ階層に置き、GitHub Pagesで公開します。

【操作】
タイトルからゲーム開始。光る印をタップして探索。
星を拾うと保管箱に入り、窓の夜空で星座作りができます。
星は5つ。5つ集まるとセラが望遠鏡へ移動します。
望遠鏡のピントを合わせ、瞳の光を取り出すとセラが止まります。
セラを調べてスタッフ室の鍵を発見し、スタッフ室でリモコンを入手。
テレビでニュースを見た後、午前0時〜0時05分（端末時刻）またはDEVボタンで流れ星が現れます。
新しい星を望遠鏡の瞳に戻して、エンディングへ。

【BGMとエンディング音源】
ゲーム内BGMと効果音はブラウザで合成します。iOS等で音が出ない場合は一度タップ操作をしてください。
エンディングの歌唱音源は同梱していません。使用権限のある音源を ending_song.mp3 として同じフォルダに置くと、エンディング内で再生できます。
音源がない場合は歌唱は流れません（代替の録音音源などはありません）。

【注意】
ブラウザのlocalStorageへVer.7のセーブデータを保存します。以前の試作版とは別キーです。
