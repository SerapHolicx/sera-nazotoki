宵空天文台 Ver.8 — スマホ縦型・三画面探索版

使い方：
1. ZIPの中身をすべて同じフォルダに展開する。
2. GitHub Pagesのリポジトリのルートに index.html と PNG 全ファイルをアップロードする。
3. 公開URLを開く。既存のブラウザセーブとは別のVer.8用の進行状況を使用します。

操作：
・左右のボタンで図書コーナー／観測室／管理コーナーを切り替える。
・画面内の名前がついた探索箇所をタップする。
・5つの星を拾うとセラが望遠鏡に移動する。
・「星空を見る」で、いつでも星を夜空へ置くことができる。
・星の回収後は探索箇所の光が消える。
・エンディングの歌唱音源は同梱していません。使用許可のある音源ファイルを ending_song.mp3 の名前で同じフォルダに置くと、エンディングで「歌を再生」を押して再生できます。
・DEV：流れ星は、テスト用に午前0時の条件を飛ばすボタンです。通常はニュース確認後、端末の時刻が00:00〜00:04のときに出現します。

動作確認：JavaScript 構文検査、画像ファイルの存在確認、ZIPの整合性検査を実施。
制限事項：iPhone Safari での実機通しプレイは実施できていません。エンディング歌唱音源は未収録です。
