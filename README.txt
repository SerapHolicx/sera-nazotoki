宵空天文台 Ver.6（試作）
========================

1. index.html をブラウザで開いてプレイできます。
2. GitHub Pagesへ公開するときは、ZIP内の index.html と画像一式を同じ階層にアップロードしてください。
3. タップで5か所の星を集め、窓でいつでも星を配置できます。子謎は一時的に外しています。
4. 5つ目を拾って画面を閉じると、セラが望遠鏡まで歩きます。
5. 望遠鏡はピントを合わせると別のものが見えてきます。
6. セラの光が消えたあとスタッフ室へ入れます。テレビはリモコン入手後に切り替えられます。
7. DEV 🌠 は流れ星のテストボタンです。実時間では午前0時から5分間に流れ星が出現します。

【歌ってみた音源について】
あなたの『星座になれたら』の音源データ自体は、このZIPには含まれていません。
使用権限のある MP3 ファイルを ending_song.mp3 のファイル名で、この index.html と同じ階層に置くと、
エンディングの「♪ エンディングを再生」でゲーム内ビジュアルと一緒に再生を試みます。
MP3ファイルがないときは、仮のシンセサイザー音が再生されます。
歌唱データやオケの二次利用の権利条件はご自身で確認してください。

iPhone Safariでは音声の自動再生を制限することがあるため、ユーザー操作ボタンから再生します。
なお実機の通しプレイはこの環境からはできていません。
